# Erste Teplo — датасет для разметки

Фото экранов квартирных теплосчетчиков и их разметка для обучения модели распознавания показаний.

- `batches/<партия>/images/` — фото, `manifest.jsonl` — список, `labels.jsonl` — разметка.
- `spec/` — правила и схема разметки (генерируются из основного проекта).
- `tools/validate.py` — проверка разметки.
- `CLAUDE.md` — задание для сессии Claude, которая размечает фото.

Размеченные партии импортируются в панель проверки, где каждую разметку подтверждает человек.
